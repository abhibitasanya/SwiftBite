\Large{\textbf{Outcome of the Project}}

\vspace{5mm}

\end{center}

The current outcome of \textbf{``SwiftBite: An Intelligent Food Ordering System''} is a full-stack academic prototype. Its React and TypeScript frontend provides a landing page, registration and login, a sample restaurant storefront, menu and cart interactions, checkout and order-status demonstrations, a zoomable OpenStreetMap view centered on Bhubaneswar, and role-specific portal interfaces.

The Node.js and Express backend exposes APIs for authentication, restaurant and profile data, menu management, image uploads, orders, dashboards, and chatbot assistance. The backend is connected to MySQL, its eight-table schema has been initialized, and the restaurant API was confirmed to return database-backed records. File-backed authentication data remains a fallback if database operations fail. The frontend currently uses bundled sample data for the customer restaurant and menu experience; its cart and checkout screens do not create persistent orders or process payment transactions.

The configured Gemini integration returned a generated recipe response during chatbot testing. The primary model retries transient failures and falls back to a secondary model; local rule-based replies remain available if both model calls fail or Gemini is unavailable. The chatbot is not connected to live menu, profile, or order data. The Bhubaneswar map uses OpenStreetMap tiles and a static approximate city-center marker; it does not track a rider. The database-backed restaurant API is verified, while full authentication-to-database integration, connecting the customer storefront to database-backed catalogue data, persistent customer ordering, payment processing, and live delivery tracking remain outside the completed scope.
