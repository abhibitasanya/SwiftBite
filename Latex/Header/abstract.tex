\Large{\textbf{Abstract}}

\vspace{5mm}

\end{center}

\justifying

SwiftBite is a web-based food-ordering prototype developed to demonstrate a customer ordering experience alongside role-specific portal interfaces and a supporting backend API. The frontend is built with React, TypeScript, and Vite. It includes a landing page, account registration and login screens, restaurant and menu browsing, a shopping cart, checkout, order-status screens, and profile features.

\vspace{0.5cm}

The customer storefront currently uses bundled sample restaurant and menu data. Cart, checkout, and order-status interactions are demonstrations and do not yet create persistent orders or process payments. The frontend communicates with the backend for account registration and login and for chatbot assistance. The Express and TypeScript backend exposes additional API routes for restaurants, profiles, menu items, uploads, orders, dashboards, and chatbot requests. The backend is connected to MySQL: the eight-table schema was initialized, four restaurants and four categories were seeded, and the restaurant API was verified to return database-backed records. Authentication retains a file-backed fallback if database operations fail.

\vspace{0.5cm}

The chatbot can use the Google Gemini service when a server API key is configured; a local rule-based response function is available as a fallback. The admin, restaurant-owner, and delivery-partner portals are demonstration interfaces and are not protected by complete server-side role authorization. This report describes the implemented prototype and distinguishes it from integrations and production features that remain future work.
