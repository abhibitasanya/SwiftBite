You are an award-winning Senior Product Designer from Apple, Airbnb, Zomato, Stripe and Linear.

Your task is NOT to redesign an existing UI.

Your task is to completely rethink and redesign the entire user experience of a premium food delivery platform called "SwiftBite."

SwiftBite should not look like a college project.

It should look like a startup that has raised millions in funding and is preparing to launch globally.

====================================================
DESIGN PHILOSOPHY
====================================================

Create a clean, elegant, premium and modern design.

The interface should feel effortless, luxurious and trustworthy.

Think about how users actually order food.

Every screen should reduce user effort.

Every interaction should feel natural.

Avoid clutter.

Use plenty of whitespace.

Maintain perfect visual hierarchy.

Every button, card and section should feel intentional.

The design should make users feel excited to order food.

====================================================
TARGET USERS
====================================================

• College students
• Working professionals
• Families
• Elderly users
• First-time smartphone users

The interface should be extremely simple and intuitive.

A person should understand how to use the app without instructions.
