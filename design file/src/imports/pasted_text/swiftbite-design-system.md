You are an award-winning Senior Product Designer who has designed products for Apple, Airbnb, Uber Eats, Zomato, Swiggy, Stripe and Linear.

Your task is to design a complete production-ready food delivery ecosystem called SwiftBite.

This is NOT a simple food ordering app.

It is a complete platform consisting of four user roles connected through one backend.

The final design should feel like a real commercial application that could launch on the Play Store or App Store.

The interface must be elegant, modern, premium, highly usable and extremely polished.

Never make it look like a college project.

====================================================

PROJECT

SwiftBite

Tagline

Fast. Fresh. Delivered.

====================================================

PRODUCT STRUCTURE

The system contains four independent user experiences.

1. Customer Application

2. Restaurant Partner Application

3. Delivery Partner Application

4. Administrator Dashboard

Each experience must have its own navigation, workflow and permissions while sharing one consistent design system.

Never mix admin screens into the customer app.

Never show restaurant management screens to customers.

Never expose administrator controls publicly.

====================================================

DESIGN STYLE

Create an original identity.

Use inspiration from

• Zomato
• Uber Eats
• Apple Human Interface Guidelines
• Material Design 3
• Airbnb
• Linear

Do NOT copy any existing app.

The final result must have its own visual identity.
